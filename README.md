# Prediksi Kelulusan Mahasiswa Berdasarkan Nilai Akademik Menggunakan Algoritma KNN

## Abstract  
The  prediction  of  student  graduation  has  become  an  essential  component  in  academic  performance  analysis,  especially  in  identifying  factors  that  influence  student  success.  This  study  aims  to  develop  a  simple  prediction  model  for  student  graduation  status  using  the  K-Nearest  Neighbor  (KNN)  algorithm.  The  dataset  used  consists  of  student  academic  records,  including Grade Point Average (GPA) and total completed credits (SKS). The data were processed and divided into training  and testing sets to evaluate the model’s performance. The KNN algorithm was applied with various K values (1, 3, 5, 7, and 9)  to  determine  the  most  optimal  classification  result.  The  experiment  showed  that  the  KNN  model  achieved  the  highest  accuracy  of  90%  when  K=3,  indicating  that  the  algorithm  performs  effectively  in  classifying  students  based  on  academic  achievement.  The  results  suggest  that  KNN  can  be  utilized  as  an  initial  analytical  tool  for  predicting  student  graduation likelihood, which can later support decision-making in academic management systems.  

**Keywords**: graduation prediction, academic performance, KNN algorithm, machine learning, student analytics

## Abstrak 
Prediksi  kelulusan  mahasiswa  merupakan  salah  satu  aspek  penting  dalam  analisis  kinerja  akademik,  khususnya  untuk mengidentifikasi  faktor-faktor  yang  memengaruhi  keberhasilan  studi.  Penelitian  ini  bertujuan  untuk  membangun  model prediksi sederhana terhadap status kelulusan mahasiswa  menggunakan algoritma  K-Nearest Neighbor (KNN). Dataset  yang digunakan terdiri dari data akademik mahasiswa seperti Indeks Prestasi Kumulatif (IPK) dan jumlah Satuan Kredit Semester (SKS)  yang  telah  ditempuh.  Data  diolah  serta  dibagi  menjadi  data  latih  dan  data  uji  untuk  mengukur  kinerja  model. Algoritma  KNN  diuji  dengan  beberapa  nilai  K  (1,  3,  5,  7,  dan  9)  guna  memperoleh  hasil  klasifikasi  paling  optimal.  Hasil pengujian  menunjukkan  bahwa  nilai  K=3  memberikan  akurasi  tertinggi  sebesar  90%,  yang  menandakan  bahwa  algoritma KNN  mampu  melakukan  klasifikasi  secara  efektif  berdasarkan  pencapaian  akademik  mahasiswa.  Temuan  ini  menunjukkan bahwa  algoritma  KNN  dapat  digunakan  sebagai  alat  analisis  awal  dalam  memprediksi  potensi  kelulusan  mahasiswa  serta mendukung pengambilan keputusan dalam sistem manajemen akademik.  

**Kata kunci**: prediksi kelulusan, kinerja akademik, algoritma knn, machine learning, analisis mahasiswa
